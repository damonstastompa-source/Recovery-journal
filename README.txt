RECOVERY JOURNAL — PHONE INSTALLABLE PWA

1. Host these files on any HTTPS static web host.
2. Open the HTTPS URL in Safari on iPhone.
3. Tap Share → Add to Home Screen.
4. Launch Recovery Journal from the Home Screen.

All journal/meeting/recovery data is stored in the browser's localStorage on the device. No server/database is used by this app.

This MVP includes:
- opens to the current date
- clean-date setting and live clean-time counter
- 3 affirmations
- 3 gratitude entries
- journal entry
- calendar
- meeting records
- automatically learned meeting templates / Quick Enter
- remembered table topics
- search
- browser print/PDF
